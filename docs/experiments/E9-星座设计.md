# E9 星座设计（逆向设计性实验）

| | |
|---|---|
| 实验编号 | E9 |
| 建议课时 | 45 min |
| 难度 | 进阶 |
| 前置知识 | 网格拓扑跳数模型（E6）、轻载/拥塞判定（E4/E7） |
| 对应代码 | `satviz/experiments.py::_run_e9`，判据源自 `tests/test_experiments.py` E9 用例 |

## 1. 实验目的

- 掌握**逆向设计**方法学：给定端到端性能约束（时延/丢包/跳数上限），
  反推可行的星座参数区域，而不是"先设计、后验证"；
- 理解星座规模（平面数 P、每平面卫星数 M）与业务速率对端到端
  性能的耦合影响，体会**规模—时延—负载**三者的工程权衡；
- 学会用**多组方案迭代 + 对比表**的方式逼近达标方案，并从达标解
  集合中按成本（星数）与余量择优。

## 2. 预备知识

### 2.1 网格拓扑跳数-时延模型（同 E6）

Walker 星座抽象为 P×M 网格：同平面星间链路成环（相位方向），
跨平面相邻连接（轨道方向，不闭合）。GS-A 接入左下角 (0,0)，
GS-B 下行挂在右上角 (P−1, ⌊M/2⌋)：

```
最短跳数 hops = (P−1) + ⌊M/2⌋        （环内走短弧）
e2e = 接入 5 + hops × ISL 8 + 下行 6 ms = 11 + 8×hops (ms)
```

### 2.2 目标约束（达标线）

本实验为**逆向设计**：目标先于方案给定——

| 约束 | 达标线 | 说明 |
|------|--------|------|
| 端到端时延 e2e | ≤ 40 ms | 每跳传播 8 ms，时延预算决定跳数预算 |
| 丢包率 loss | ≤ 1% | 源速率须保持轻载（ISL 容量充裕） |
| ISL 跳数 hops | ≤ 4 | 鼓励紧凑设计，兼顾切换与路由收敛 |

**约束换算**是逆向设计的第一步：时延预算 40 − 11 = 29 ms，
每跳 8 ms → 可行跳数 ≤ ⌊29/8⌋ = 3。注意显式跳数约束（≤4）比
时延隐含约束更宽松，**两者的交集才是达标区**——这正是多约束
设计的典型形态。

### 2.3 逆向设计方法论

1. **约束换算**：把性能指标翻译成设计预算（时延预算 → 跳数预算）；
2. **参数空间搜索**：由跳数预算反推可行 (P, M) 区域；
3. **迭代验证**：多组运行对照判据找差距，按结论区引导修正；
4. **对比择优**：在达标方案中按星数（成本）与时延余量取舍。

## 3. 实验步骤

1. 启动平台，打开实验台选择 E9，阅读目标约束与网格模型；
2. 由时延预算推算可行跳数范围，拟定第一组 P×M 方案（可激进
   可保守）并运行，对照判据与「目标约束」徽标条找差距；
3. 按结论区引导迭代：调整 P、M 或源速率重跑——平台自动把每次
   运行记入历史，累计 **≥3 组不同 P×M 方案**；
4. 在「方案对比」表（P×M / 源速率 / e2e / 跳数 / 得分）中
   观察各方案与达标线的距离，锁定满足全部约束的方案；
5. 以达标方案为最终运行（判据全绿、得分最高）；
6. 填写「分析结论」，下载报告并回答思考题。

> 提示：判据按权重计分——时延 40%、跳数 30%、丢包 20%、
> 迭代方案数 10%；只跑一次（哪怕达标）拿不到迭代判据的分。

## 4. 判据与记录（设计型，判据带权重）

| 判据 | 权重 | 判定 |
|------|------|------|
| 时延达标 e2e ≤ 40 ms | 40% | 实测 e2e ≤ 40 ms |
| 丢包达标 loss ≤ 1% | 20% | 实测丢包率 ≤ 1% |
| 跳数紧凑 hops ≤ 4 | 30% | 理论跳数（曼哈顿公式）≤ 4 |
| 设计迭代 ≥ 3 次不同方案 | 10% | 不同 (P, M) 组合数（含本次）≥ 3 |

本实验不设参数扫描分（评分卡注明"设计型实验以达标判定计分"），
总分由四项判据 + 预习测验 + 思考题构成。结果区随行下发
「目标约束」徽标条（实测值 vs 达标线，达标绿/未达标红）与
「方案对比」表（历史迭代 + 本次，本次行高亮）。

## 5. 思考题提示（不给答案）

1. **解的多解性**：满足全部约束的 (P, M) 组合是否唯一？
   在达标方案中你如何权衡星数（发射/运维成本）与时延余量
   （应对未来负载增长的抗性）？可从对比表中星数最小与余量
   最大两个极端展开。
2. **速率敏感性**：把源速率从 200 提到 400 pps，轻载假设还
   成立吗？丢包与时延判据哪个会先失守？结合 E2 的 ρ→1 悬崖
   与 E7 的容量中断门限分析。

## 6. 延伸

E6（星座规模探索）给出"规模 → 跳数 → 时延"的正向模型，
本实验反其道而行："约束 → 预算 → 参数区域"。真实星座设计
（如 Iridium、Starlink 相位优化）还要叠加覆盖连续性、切换
频率、链路预算（E7）与故障韧性（E8）等约束，达标区会进一步
收缩——多约束下的 Pareto 前沿搜索是星座优化的核心课题。
