# 星桥教学实验指导书（E1–E4 + E8 + E9）

本目录包含基于星桥平台的编号教学实验，全部在**独立沙箱引擎**中运行，
不影响主星座仿真。每个实验都遵循同一教学模式：

> **看理论 → 跑仿真 → 对账（理论值 vs 实测值）→ 出报告**

（E8 为诊断型实验：**观测 → 边界 → 假设 → 提交证据**，两阶段流程；
E9 为逆向设计型实验：**约束换算 → 迭代设计 → 对比择优**，
判据按达标 + 迭代方案数计权。E5~E7 无独立指导书，
核心判据见 [GUIDE.md §6.9](../../GUIDE.md)。）

| 编号 | 名称 | 知识点 | 难度 | 建议课时 |
|------|------|--------|------|----------|
| E1 | [时延分解与对账](E1-时延分解与对账.md) | 传播时延 / 发送时延 / 轻载链路 | 入门 | 45 min |
| E2 | [M/D/1 排队模型](E2-MD1排队模型.md) | 排队论 / Little 公式 / 稳态测量 | 基础 | 45 min |
| E3 | [链路切换丢包](E3-链路切换丢包.md) | 星地切换 / 队列堆积 / 丢包口径 | 进阶 | 45 min |
| E4 | [QoS 严格优先级](E4-QoS严格优先级.md) | 拥塞控制 / 区分服务 / 优先级调度 | 进阶 | 45 min |
| E8 | [链路故障诊断](E8-故障诊断.md) | 容量骤降拥塞 / 分段排查 / 证据链 | 进阶 | 45 min |
| E9 | [星座设计](E9-星座设计.md) | 逆向设计 / 目标约束 / 方案迭代对比 | 进阶 | 45 min |

## 使用方法（学生端）

1. 双击项目根目录 `start_starbridge.bat`，浏览器自动打开平台页面；
2. 点击右上角 **「教学实验」** 按钮打开实验面板；
3. 选择实验卡片，展开 **「实验参数」** 阅读场景配置；
4. 点击 **「运行实验」**，观察进度条与阶段提示（预热 / 仿真推进 / 数据测量）；
5. 运行结束查看 **理论-实测对账表**，确认每一行判据是否通过；
6. 在结果区填写 **「分析结论」**（必填），点击 **「下载实验报告 (HTML)」**
   生成报告（含参数-结果对比表与分析结论段），填写姓名学号后打印或提交。

## 对账判据（教师速查）

| 实验 | 核心判据 | 容差 |
|------|----------|------|
| E1 | e2e = 21 ms + 0.037 ms = 21.037 ms | ±1 ms |
| E2 | e2e = 传播 6 + 服务 6 + Wq 12 ≈ 24 ms；ρ ≈ 0.8 | ±3 ms / ±0.05 |
| E3 | 切换丢包尖峰 = 队列 200 + 在途 1 = 201 包 | ±1 包 |
| E4 | HIGH 时延与丢包 < BE；BE loss > 0 | 关系判据 |
| E8 | 根因链路定位（70%）+ 证据链完整性（30%） | 诊断判定 |
| E9 | 目标约束达标（时延 40% / 跳数 30% / 丢包 20%）+ 迭代 ≥3 组方案（10%） | 设计判定 |

全部实验采用**固定随机种子**（42 / 99 / 7 / 11 / 8 / 9），结果可复现；判据与
`tests/` 目录下已通过的对账测试一一对应，平台自动判定即为课程判分标准。

## 面向教师

- 各实验的场景参数固化在 `hypatia-master/satviz/experiments.py`，
  修改参数即可定制校本实验；
- 实验运行不占用主仿真：学生可一边观察星座运行，一边在沙箱中做实验；
- 报告由浏览器本地生成（HTML，可直接打印为 PDF），包含参数表、
  对账表、**参数-结果对比表（多次尝试）**与**学生分析结论**段，
  便于统一批改。
